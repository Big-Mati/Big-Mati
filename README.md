### 🚀 Sobre mí

- 💻 **Enfoque actual:** Desarrollo de aplicaciones web modernas, apps nativas para Android y arquitecturas de automatización inteligente.
- 🧠 **Especialidad en IA:** Integración de modelos generativos (**Google Gemini / Vertex AI**), visión computacional, *machine learning* y agentes automatizados con **n8n**.
- 🛠️ **Sistemas y Hardware:** Diseño de prototipos con microcontroladores (**Arduino / C++**), administración de entornos **Linux** y armado/optimización de hardware de alto rendimiento.
- 🤝 **Colaboraciones:** Abierto a colaborar en proyectos de software, plataformas escalables e integraciones de IA orientadas a resolver problemas reales.
- 💬 **Pregúntame sobre:** Python, React, PHP, Java para Android, C++, MySQL, n8n, Google Cloud y configuración de servidores/hardware.
